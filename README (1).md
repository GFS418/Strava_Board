# A Summer of Running — Strava Data Dashboard

An exploratory analysis of a raw Strava / Garmin FIT data dump: **40,000+ GPS-tracked sample points across 64 activities**, reconstructed into a portrait of one runner's summer.

👉 **[View the live dashboard](https://YOUR-USERNAME.github.io/strava-dashboard/)** *(after enabling GitHub Pages — see below)*

![Aerobic decoupling density map](assets/04-aerobic-decoupling.png)

## What's inside

The dashboard walks through five figures, three basic visual techniques and one advanced:

| Figure | Technique | Question it answers |
|--------|-----------|---------------------|
| Night runner | Histogram | When does this person run? |
| Cadence vs. speed | Scatter (HR-colored) | Does speed come from stride or turnover? |
| Pace by day of week | Box + Violin | How does effort vary across the week? |
| Aerobic decoupling | 2-D hexbin density + drift curve | Does efficiency hold over a run? |
| Form power vs. bounce | Scatter + linear fit | Is the Stryd power data physically consistent? |

### Headline findings
- **A night runner in Ann Arbor, MI** — ~80% of runs start after 8pm.
- **Speed comes from stride length, not turnover** — cadence sits below the folk-wisdom 180 spm.
- **Structured training** — tight weekday pacing, wide-open weekends.
- **Solid aerobic durability** — efficiency holds ~60% of each run, then decouples modestly.
- **Actionable lever** — less vertical bounce means less wasted power.

## Publishing to GitHub Pages

1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to `Deploy from a branch`, branch `main`, folder `/ (root)`.
4. Save. Your dashboard will be live at `https://YOUR-USERNAME.github.io/strava-dashboard/` within a minute or two.
5. Update the live-dashboard link at the top of this README with your username.

## Reproducing the analysis

The figures are generated by `notebook/strava_report.ipynb`. To re-run it you'll need the source `strava.csv` (a per-sample export of `.fit.gz` files) in the notebook's working directory, plus:

```
pandas 1.4.4 · numpy 1.21.5 · matplotlib 3.5.2 · seaborn 0.11.2 · python 3.9
```

The notebook is deterministic and reproduces every figure from a clean kernel restart (Restart & Run All).

## Notes on the data

FIT files store one row per recorded sample (~1/sec). A few encoding quirks handled in the notebook: coordinates are stored in **semicircles** (converted to degrees), `distance` is **cumulative meters** within an activity, and running cadence is `(cadence + fractional_cadence) × 2`. Stryd power fields (Power, Form Power, Vertical Oscillation, etc.) appear on only a subset of runs.

*This dashboard contains only aggregated, plotted figures — no raw GPS coordinates or personal location traces are published.*
